**Comprendre l'HTML**

**Pour créer un fichier HTML il lui faut un squelette.**  
**Il faut donc écrire ces deux lignes pour pouvoir commencer le travail.**

**\<\!DOCTYPE html\>**  Cette ligne permet de s'assurer que l'écriture du code soit bien en langue html  
**\<html lang="fr"\>** Et celle-ci permet de faire connaître que la langue principale du document est le français.

**Ensuite, il faut passer au \<head\>,\<title\>,\<body\> et ce qu'ils contiennent** 

le **\<head\>\</head\>** est désigné pour le navigateurs et donc des données non affichées à l'écran

Et donc dans le **\<head\>** il y a des données à ajouter tel que :   
**\<meta charset="UTF-8"\>** qui permet de faire savoir au moteur de recherche l'encodage à utiliser pour bien afficher les accents 

**\<link rel="stylesheet" href="Nomduficher.css"\>** cette ligne va permettre de connecter en cas de besoin le document css à un document HTML.  
Et ensuite pouvoir fermer le groupe \<head\> avec un \</head\>

Le **\<title\>** permet de modifier le texte inscrit dans le nom de l'onglet du navigateur.  
Exemple : **\<title\>** Commande de base HTML **\</title\>** donnera pour nom d'onglet "Commande de base HTML".

le **\<body\>\</body\>** est le groupe du code ou tout ce qui sera affiché sur la page web doit être écrit.
